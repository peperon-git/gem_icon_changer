# Gemアイコン変更
GeminiのGemアイコンを、好きな画像で表示するためのChrome拡張です。

## インストール
1. Chrome で `拡張機能を管理` を開きます。
2. 右上の `デベロッパー モード` をオンにします。
3. `パッケージ化されていない拡張機能を読み込む` をクリックします。
4. このフォルダを選択します。
5. `https://gemini.google.com` を開きます。

## 使い方
1. Chromeの拡張機能アイコンから `Gemアイコン変更` を開きます。
2. Geminiに表示されているGem名をフルネームで入力します。
3. 2MB 以下の画像を選びます。
4. `この画像を保存` をクリックします。
5. すぐに反映されない場合は、Geminiのページを再読み込みします。

保存した画像はChromeのローカルストレージに保存されます。画像が大きすぎて保存できない場合は、先にリサイズまたは圧縮してください。

## 注意
この拡張は、Gemini本体のGem設定に画像をアップロードするものではありません。
あなたのChrome上で、Gem名が一致するアイコンの表示だけを置き換えます。対象はGem一覧、Gemの個別ページ、マイGem制作画面などです。
Gem名を変更した際は画像を保存し直してください。
